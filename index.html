History

The Historical Internet of All Recursive

Follow the stream from packet switching to the archived Web. Open an era, then expand any milestone to follow its source.

  1. 1960s–1980s Networks become an Internet
    1. 1969 ARPANET comes online

      Four host computers joined the early ARPANET by the end of the year, testing how computers could communicate over a packet-switched network.

      Internet Society · A Brief History of the Internet
    2. 1983 ARPANET switches to TCP/IP

      On January 1, ARPANET changed to TCP/IP. Shared protocols made it possible for independently built networks to exchange traffic.

      Internet Society · The TCP/IP transition
    3. 1986 NSFNET extends research networking

      The U.S. National Science Foundation began building NSFNET, which grew into a major backbone for research and education networks.

      Internet Society · Internet and related networks
    4. 1987 DNS standards describe recursive lookup

      RFC 1034 describes a distributed naming system. A recursive resolver can follow referrals across the DNS hierarchy to answer a client’s query.

      RFC 1034 · Domain names
  2. 1989–1990s The Web links documents
    1. 1989 The World Wide Web is proposed

      At CERN, Tim Berners-Lee proposed using hypertext to connect information across computers. The Web was built on top of the existing Internet.

      CERN · A short history of the Web
    2. 1990 The first browser and web server run at CERN

      By the end of 1990 the first web browser and server were working. The first site explained the Web project itself.

      CERN · Visit the restored first website
    3. 1993 The Web opens and Mosaic arrives

      CERN released its Web software into the public domain. Mosaic made pages with inline images easier to browse.

      CERN · The birth of the Web Computer History Museum · Networking & the Web
  3. 1990s onward The Web remembers itself
    1. Explore archived versions of the Web

      The Wayback Machine lets you enter a URL, choose an available capture date, and open an earlier version of the page. Captures can lead to other archived pages, and some links or assets may be missing.

      Internet Archive · Browse the Wayback Machine
